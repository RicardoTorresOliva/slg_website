# FIXTURE NEGATIVO de `check:literacy` (R-26)

No es documentación del proyecto: es un índice **al que le falta algo**, para que el freno se vea en
rojo por el motivo esperado antes de que su verde signifique algo.

Enlaza uno de los dos design docs y se olvida del otro — que es exactamente como se pierde un
documento de verdad: nadie decide dejarlo fuera, simplemente se escribe uno nuevo y no se toca el
índice.
